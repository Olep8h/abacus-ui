# Tokens

Source: Figma Community file **Simple Design System** by Figma. The variables export is committed
untouched as `packages/ui/src/tokens/tokens.json`; everything below is rendered from the file the
build script generates from it, so this page cannot drift from `tokens.css`.

Pipeline: `tokens.json` → `pnpm build:tokens` → `tokens.css` (`--sds-*` custom properties, light on
`:root`, dark on `[data-theme="dark"]`) → `theme.css` (Tailwind `@theme`, semantic names only).

## Semantic colours

These are the only colours Tailwind utilities can reach: `bg-brand`, `text-fg-secondary`,
`border-line-danger`. Each swatch is shown in both themes.

## Primitive ramps

The ramps the semantic tokens alias. Available as CSS variables for charts and docs, deliberately
_not_ exposed as utilities, so a component cannot skip the semantic layer.
