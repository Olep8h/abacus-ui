## Props

Columns are built with `createDataTableColumns<Row>()`, TanStack Table's typed column helper bound
to this table's feature set. `meta.align: "end"` right-aligns a numeric column.

## States

Loading, empty and error are props, not conditions the consumer renders around the table. The

## When not to use it

- **Tens of thousands of rows without a server.** Sorting and paging happen in memory here.
  Past a few thousand rows, sort on the server and virtualise.
- **Row editing.** This is a read-and-sort surface. Inline editing changes the keyboard contract
  (grid navigation) and belongs to a different component.
- **Tree or grouped data.** Expandable rows are not registered; add the feature deliberately
  rather than nesting tables.
- **As a layout tool.** If the columns are not data, it is a list.
