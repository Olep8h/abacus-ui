## When not to use it

- **Navigation.** If activating it changes the URL, it is a link. Use `asChild` with your router's
  link so it keeps prefetching, middle-click and "open in new tab".
- **Toggles.** A button that stays "on" needs `aria-pressed` or a Switch; a Button with a
  different colour is not a state.
- **Destructive without confirmation.** `variant="destructive"` is a colour, not a safeguard.
  Pair it with a `Dialog` for anything irreversible.
- **More than one primary per view.** If everything is primary, nothing is.
