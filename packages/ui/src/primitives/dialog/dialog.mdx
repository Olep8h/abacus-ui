## Props

`Dialog` accepts Radix's root props. The parts: `DialogTrigger`, `DialogContent`
(`showClose`), `DialogTitle`, `DialogDescription`, `DialogFooter`, `DialogClose`.

<Controls />

## Focus and motion

- On open, focus moves into the panel (first focusable element, otherwise the panel).
- `Tab` cycles inside the panel; `Escape` and outside click close it.
- On close, focus returns to the element that opened it. The test for this is in `dialog.test.tsx`.
- The panel animates `transform` + `opacity` on a spring. Because a spring is physics, an
  interrupted close-then-open reverses from wherever it is instead of jumping. With
  `prefers-reduced-motion: reduce` there is no motion at all.

## When not to use it

- **Non-blocking information.** A toast, an inline banner or a popover does not steal focus.
- **Multi-step flows.** Wizards inside a modal trap the user; use a page.
- **Anything with a table or a long form.** If the content needs scrolling, it needs a route.
- **As a second dialog.** Stacked modals mean the first one should not have been modal.
